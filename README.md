# AI社畜評論家

あなたの今日を、AIが容赦なく評価します。

## 🌐 オンライン体験 / Live Demo

👉 **[https://ai-comment-5mof.onrender.com/](https://ai-comment-5mof.onrender.com/)**

> ※ 無料プランでホスティングしているため、初回アクセス時は起動に30秒〜50秒ほどかかる場合があります。

## 概要

「AI社畜評論家」は、ユーザーが入力した日常・仕事・研修内容に対して、AI風の評論コメントを生成するエンタメ系Webサイトです。複数のAIモードから選択でき、同じ入力内容でもAIモードによって違う雰囲気の回答が表示されます。

## 主な機能

### 1. コメント生成機能
- ユーザーの入力内容に基づいて、選択したAIモードに応じた評論コメントを生成
- 5段階評価（★）を表示
- 入力内容のキーワードに応じて評価が変動

### 2. AIモード
以下の5つのモードから選択可能：

- **毒舌AI** 😈
  - 辛口で少し意地悪だが、最後に少しだけ励ます
  
- **優しいAI** 😊
  - ユーザーを肯定し、前向きに励ます
  
- **上司AI** 👔
  - ビジネス風、評価面談風、少しプレッシャーをかける
  
- **同期AI** 🤝
  - 友達っぽく共感しながら軽くツッコむ
  
- **限界社畜AI** 😵
  - 疲れ切った社畜目線で、現実味のあるコメントをする

### 3. 履歴機能
- 生成した結果をLocalStorageに自動保存
- 入力文、AIモード、生成結果、評価、日時を履歴として表示
- 履歴削除機能

### 4. ランダムお題機能
- 「今日のお題」ボタンで、ランダムなお題が入力欄に自動入力
- 15種類のお題を用意

### 5. お問い合わせフォーム
- 名前、メールアドレス、問い合わせ内容を入力可能
- フォームバリデーション機能

## 技術スタック

- **バックエンド**: Node.js, Express, TypeScript
- **フロントエンド**: EJS, JavaScript, CSS
- **データ保存**: LocalStorage（クライアント側）
- **ポート**: 8091

## セットアップ方法

### 必要な環境
- Node.js（v14以上推奨）
- npm

### インストール手順

1. リポジトリをクローンまたはダウンロード
```bash
git clone <repository-url>
cd AIComment
```

2. 依存パッケージをインストール
```bash
npm install
```

3. TypeScriptをコンパイル
```bash
npm run build
```

4. サーバーを起動
```bash
npm start
```

5. ブラウザで以下のURLにアクセス
```
http://localhost:8091
```

### Windows用簡単起動

Windowsユーザーは `start.bat` をダブルクリックするだけで起動できます。

```bash
start.bat
```

このスクリプトは以下を自動で実行します：
- Node.jsのインストール確認
- 依存パッケージのインストール（初回のみ）
- TypeScriptのコンパイル
- サーバーの起動

## 使い方

### 1. ホーム画面
1. テキストエリアに今日の出来事や学習内容を入力（200文字以内）
2. 5つのAIモードから1つを選択
3. 「評価を生成」ボタンをクリック
4. AI評論コメントと評価が表示されます

### 2. ランダムお題
- 「今日のお題」ボタンをクリックすると、ランダムなお題が入力されます
- そのまま評価を生成することも、編集してから生成することもできます

### 3. 履歴の確認
- ナビゲーションメニューから「履歴」をクリック
- 過去の評価結果を時系列で確認できます
- 「履歴をすべて削除」ボタンで全履歴を削除できます

### 4. お問い合わせ
- ナビゲーションメニューから「お問い合わせ」をクリック
- 必要事項を入力して送信できます

## 入力制限

以下の制限があります：
- 最大文字数: 200文字
- 禁止文字: `<`, `>`, `&`, `;`
- 空欄での送信は不可

## 評価システム

評価は以下の要素で決定されます：

### ポジティブキーワード（評価UP）
- 頑張った、勉強、完成、成功、達成、学んだ、成長、努力、挑戦、克服

### ネガティブキーワード（評価DOWN）
- 寝坊、何もしてない、ミス、失敗、サボった、遅刻、できなかった

### その他の要素
- 文字数が50文字を超えると評価が少し上がります
- 基本評価は★★★（3つ星）からスタート

## デザインコンセプト

- **テーマ**: 近未来AI × 社畜 × ちょっとブラックユーモア
- **配色**:
  - 背景: ダーク系（深い青紫）
  - メインカラー: 深緑、青紫
  - アクセントカラー: ネオン風の黄色・オレンジ
- **レスポンシブ対応**: スマートフォンでも快適に利用可能

## 注意事項

- このアプリケーションは外部AI APIを使用していません
- コメントはルールベースで生成されるため、実際のAIではありません
- 履歴はブラウザのLocalStorageに保存されるため、ブラウザのデータを削除すると履歴も消えます
- お問い合わせフォームは送信内容をコンソールに出力するのみで、実際のメール送信は行いません
