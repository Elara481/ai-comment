## 概要 / 项目简介

「AI社畜評論家」は、ユーザーが入力した日常・仕事・研修内容に対して、AI風の評論コメントを生成するエンタメ系Webサイトです。複数のAIモードから選択でき、同じ入力内容でもAIモードによって違う雰囲気の回答が表示されます。

「AI打工人点评家」是一个娱乐向 Web 应用，针对用户输入的日常生活、工作或培训内容，以 AI 风格生成点评。支持多种 AI 模式，相同的输入在不同模式下会呈现截然不同的风格与语气。

## 主な機能 / 主要功能

### 1. コメント生成機能 / 点评生成
- ユーザーの入力内容に基づいて、選択したAIモードに応じた評論コメントを生成  
  根据用户输入及所选 AI 模式，自动生成对应风格的点评内容
- 5段階評価（★）を表示 / 显示五星评分（★）
- 入力内容のキーワードに応じて評価が変動  
  评分随输入关键词动态变化

### 2. AIモード / AI 模式
以下の5つのモードから選択可能 / 可从以下 5 种模式中选择：

- **毒舌AI** 😈  
  辛口で少し意地悪だが、最後に少しだけ励ます  
  毒舌刻薄，但最后还是会给一点点鼓励

- **優しいAI** 😊  
  ユーザーを肯定し、前向きに励ます  
  全力肯定用户，积极向上地鼓励

- **上司AI** 👔  
  ビジネス風、評価面談風、少しプレッシャーをかける  
  商务风格，绩效面谈腔，略带压迫感

- **同期AI** 🤝  
  友達っぽく共感しながら軽くツッコむ  
  像朋友一样共情，顺带轻松吐槽

- **限界社畜AI** 😵  
  疲れ切った社畜目線で、現実味のあるコメントをする  
  以精疲力竭的打工人视角，给出最真实的点评

### 3. ユーザーインタラクティブ評価・反論機能 / 用户互动评价与反驳功能（新功能 / 新功能）
- **ユーザーによる逆評価 / 用户反向评分**: AIの評論結果に対して1〜5段階（★）で評価可能  
  可对 AI 点评结果进行 1～5 星的反向评分
- **理想の回答 / 反論入力 / 理想回答与反驳输入**: AIの評価に納得いかない場合、自分の反論や理想のコメントを記録可能  
  对 AI 评价不满时，可记录自己的反驳意见或理想答案
- **フィードバックの保存 / 反馈自动保存**: つけた評価と反論は履歴に自動保存され、いつでも振り返り可能  
  评分与反驳内容自动保存至历史记录，随时可回顾

### 4. 社畜広場（パブリックコミュニティ）/ 打工人广场（公共社区）🏢
- **全ユーザーの投稿をリアルタイム共有 / 全员动态实时共享**: 他のユーザーの日常、AIの辛口コメント、魂の反論を一覧表示  
  实时展示其他用户的日常、AI 点评及灵魂反驳
- **共感・いいね（点赞）機能 / 点赞功能**: 面白い投稿や共感できる反論にワンクリックでハート/いいねが可能  
  一键为有趣的帖子或引发共鸣的反驳点赞 ❤️
- **クラウドデータベース（Supabase）対応 / 云数据库支持（Supabase）**: Supabase を連携することで全投稿を永続化（未設定時も自動フォールバック対応）  
  接入 Supabase 后可永久保存所有动态（未配置时自动降级处理）

### 5. 履歴機能 / 历史记录功能
- 生成した結果およびユーザーの反論・評価をLocalStorageに自動保存  
  生成结果及用户反驳、评分自动保存至 LocalStorage
- 入力文、AIモード、生成結果、ユーザーフィードバック、日時を履歴として表示  
  历史记录展示输入内容、AI 模式、生成结果、用户反馈及时间
- 履歴削除機能 / 支持删除历史记录

### 6. ランダムお題機能 / 随机话题功能
- 「今日のお題」ボタンで、ランダムなお題が入力欄に自動入力  
  点击"今日话题"按钮，随机题目自动填入输入框
- 15種類のお題を用意 / 预置 15 种话题

### 7. お問い合わせフォーム / 联系表单
- 名前、メールアドレス、問い合わせ内容を入力可能  
  可填写姓名、邮箱及问题内容
- フォームバリデーション機能 / 表单输入验证

## 使い方 / 使用方法

### 1. ホーム画面 / 主页

1. テキストエリアに今日の出来事や学習内容を入力（200文字以内）  
   在文本框中输入今天发生的事或学习内容（200 字以内）
2. 5つのAIモードから1つを選択 / 从 5 种 AI 模式中选择一种
3. 「評価を生成」ボタンをクリック / 点击"生成点评"按钮
4. AI評論コメントと評価が表示されます / AI 点评与评分将显示在页面上

### 2. ランダムお題 / 随机话题

- 「今日のお題」ボタンをクリックすると、ランダムなお題が入力されます  
  点击"今日话题"按钮，随机题目将自动填入
- そのまま評価を生成することも、編集してから生成することもできます  
  可直接生成点评，也可编辑后再生成

### 3. 履歴の確認 / 查看历史记录

- ナビゲーションメニューから「履歴」をクリック / 点击导航菜单中的"历史记录"
- 過去の評価結果を時系列で確認できます / 可按时间顺序查看历史点评结果
- 「履歴をすべて削除」ボタンで全履歴を削除できます / 点击"删除全部历史"按钮可清空所有记录

### 4. お問い合わせ / 联系我们

- ナビゲーションメニューから「お問い合わせ」をクリック / 点击导航菜单中的"联系我们"
- 必要事項を入力して送信できます / 填写必要信息后提交

## 評価システム / 评分系统

評価は以下の要素で決定されます / 评分由以下要素决定：

### ポジティブキーワード（評価UP）/ 正面关键词（加分）
頑張った、勉強、完成、成功、達成、学んだ、成長、努力、挑戦、克服  
加油了、学习、完成、成功、达成、学到了、成长、努力、挑战、克服

### ネガティブキーワード（評価DOWN）/ 负面关键词（减分）
寝坊、何もしてない、ミス、失敗、サボった、遅刻、できなかった  
睡过头、什么都没做、失误、失败、摸鱼了、迟到、没能做到

### その他の要素 / 其他加分项
- 文字数が50文字を超えると評価が少し上がります / 输入超过 50 字时评分略微提升
- 基本評価は★★★（3つ星）からスタート / 基础评分从 ★★★（3 星）起步

## 注意事項 / 注意事项

- このアプリケーションは外部AI APIを使用していません  
  本应用不使用任何外部 AI API
- コメントはルールベースで生成されるため、実際のAIではありません  
  点评基于规则生成，并非真正的 AI
- 履歴はブラウザのLocalStorageに保存されるため、ブラウザのデータを削除すると履歴も消えます  
  历史记录保存在浏览器 LocalStorage 中，清除浏览器数据后记录将一并删除
- お問い合わせフォームは送信内容をコンソールに出力するのみで、実際のメール送信は行いません  
  联系表单仅将内容输出至控制台，不会发送实际邮件
