# 🇯🇵 日本語

## AI社畜評論家

あなたの今日を、AIが容赦なく評価します。

### 🌐 オンライン体験 / Live Demo

👉 **[https://ai-comment-5mof.onrender.com/](https://ai-comment-5mof.onrender.com/)**

> ※ 無料プランでホスティングしているため、初回アクセス時は起動に30秒〜50秒ほどかかる場合があります。

---

### 概要

「AI社畜評論家」は、ユーザーが入力した日常・仕事・研修内容に対して、AI風の評論コメントを生成するエンタメ系Webサイトです。複数のAIモードから選択でき、同じ入力内容でもAIモードによって違う雰囲気の回答が表示されます。

---

### 主な機能

#### 1. コメント生成機能
- ユーザーの入力内容に基づいて、選択したAIモードに応じた評論コメントを生成
- 5段階評価（★）を表示
- 入力内容のキーワードに応じて評価が変動

#### 2. AIモード
以下の5つのモードから選択可能：

| モード | 説明 |
|---|---|
| **毒舌AI** 😈 | 辛口で少し意地悪だが、最後に少しだけ励ます |
| **優しいAI** 😊 | ユーザーを肯定し、前向きに励ます |
| **上司AI** 👔 | ビジネス風、評価面談風、少しプレッシャーをかける |
| **同期AI** 🤝 | 友達っぽく共感しながら軽くツッコむ |
| **限界社畜AI** 😵 | 疲れ切った社畜目線で、現実味のあるコメントをする |

#### 3. ユーザーインタラクティブ評価・反論機能（新機能）
- **ユーザーによる逆評価**: AIの評論結果に対して1〜5段階（★）で評価可能
- **理想の回答 / 反論入力**: AIの評価に納得いかない場合、自分の反論や理想のコメントを記録可能
- **フィードバックの保存**: つけた評価と反論は履歴に自動保存され、いつでも振り返り可能

#### 4. 社畜広場（パブリックコミュニティ）🏢
- **全ユーザーの投稿をリアルタイム共有**: 他のユーザーの日常、AIの辛口コメント、魂の反論を一覧表示
- **共感・いいね機能**: 面白い投稿や共感できる反論にワンクリックでいいねが可能
- **クラウドデータベース（Supabase）対応**: Supabase を連携することで全投稿を永続化（未設定時も自動フォールバック対応）

#### 5. 履歴機能
- 生成した結果およびユーザーの反論・評価をLocalStorageに自動保存
- 入力文、AIモード、生成結果、ユーザーフィードバック、日時を履歴として表示
- 履歴削除機能

#### 6. ランダムお題機能
- 「今日のお題」ボタンで、ランダムなお題が入力欄に自動入力
- 15種類のお題を用意

#### 7. お問い合わせフォーム
- 名前、メールアドレス、問い合わせ内容を入力可能
- フォームバリデーション機能

### セットアップ方法

#### 必要な環境
- Node.js（v14以上推奨）
- npm

#### インストール手順

1. リポジトリをクローンまたはダウンロード
```bash
git clone <repository-url>
cd AIComment
```

2. 依存パッケージをインストール
```bash
npm install
```

3. TypeScriptをコンパイル
```bash
npm run build
```

4. サーバーを起動
```bash
npm start
```

5. ブラウザで以下のURLにアクセス
```
http://localhost:8091
```

#### Windows用簡単起動

Windowsユーザーは `start.bat` をダブルクリックするだけで起動できます。

このスクリプトは以下を自動で実行します：
- Node.jsのインストール確認
- 依存パッケージのインストール（初回のみ）
- TypeScriptのコンパイル
- サーバーの起動

### 使い方

#### 1. ホーム画面
1. テキストエリアに今日の出来事や学習内容を入力（200文字以内）
2. 5つのAIモードから1つを選択
3. 「評価を生成」ボタンをクリック
4. AI評論コメントと評価が表示されます

#### 2. ランダムお題
- 「今日のお題」ボタンをクリックすると、ランダムなお題が入力されます
- そのまま評価を生成することも、編集してから生成することもできます

#### 3. 履歴の確認
- ナビゲーションメニューから「履歴」をクリック
- 過去の評価結果を時系列で確認できます
- 「履歴をすべて削除」ボタンで全履歴を削除できます

#### 4. お問い合わせ
- ナビゲーションメニューから「お問い合わせ」をクリック
- 必要事項を入力して送信できます

### 評価システム

評価は以下の要素で決定されます：

**ポジティブキーワード（評価UP）**  
頑張った、勉強、完成、成功、達成、学んだ、成長、努力、挑戦、克服

**ネガティブキーワード（評価DOWN）**  
寝坊、何もしてない、ミス、失敗、サボった、遅刻、できなかった

**その他の要素**
- 文字数が50文字を超えると評価が少し上がります
- 基本評価は★★★（3つ星）からスタート

### 注意事項

- このアプリケーションは外部AI APIを使用していません
- コメントはルールベースで生成されるため、実際のAIではありません
- 履歴はブラウザのLocalStorageに保存されるため、ブラウザのデータを削除すると履歴も消えます
- お問い合わせフォームは送信内容をコンソールに出力するのみで、実際のメール送信は行いません

### 项目简介

「AI打工人点评家」是一个娱乐向 Web 应用，针对用户输入的日常生活、工作或培训内容，以 AI 风格生成点评。支持多种 AI 模式，相同的输入在不同模式下会呈现截然不同的风格与语气。

---

### 主要功能

#### 1. 点评生成
- 根据用户输入及所选 AI 模式，自动生成对应风格的点评内容
- 显示五星评分（★）
- 评分随输入关键词动态变化

#### 2. AI 模式
可从以下 5 种模式中选择：

| 模式 | 说明 |
|---|---|
| **毒舌AI** 😈 | 毒舌刻薄，但最后还是会给一点点鼓励 |
| **温柔AI** 😊 | 全力肯定用户，积极向上地鼓励 |
| **上司AI** 👔 | 商务风格，绩效面谈腔，略带压迫感 |
| **同事AI** 🤝 | 像朋友一样共情，顺带轻松吐槽 |
| **极限打工AI** 😵 | 以精疲力竭的打工人视角，给出最真实的点评 |

#### 3. 用户互动评价与反驳功能（新功能）
- **用户反向评分**：可对 AI 点评结果进行 1～5 星的反向评分
- **理想回答与反驳输入**：对 AI 评价不满时，可记录自己的反驳意见或理想答案
- **反馈自动保存**：评分与反驳内容自动保存至历史记录，随时可回顾

#### 4. 打工人广场（公共社区）🏢
- **全员动态实时共享**：实时展示其他用户的日常、AI 点评及灵魂反驳
- **点赞功能**：一键为有趣的帖子或引发共鸣的反驳点赞 ❤️
- **云数据库支持（Supabase）**：接入 Supabase 后可永久保存所有动态（未配置时自动降级处理）

#### 5. 历史记录功能
- 生成结果及用户反驳、评分自动保存至 LocalStorage
- 历史记录展示输入内容、AI 模式、生成结果、用户反馈及时间
- 支持删除历史记录

#### 6. 随机话题功能
- 点击"今日话题"按钮，随机题目自动填入输入框
- 预置 15 种话题

#### 7. 联系表单
- 可填写姓名、邮箱及问题内容
- 表单输入验证

- 点击导航菜单中的"联系我们"

### 评分系统

评分由以下要素决定：

**正面关键词（加分）**  
加油了、学习、完成、成功、达成、学到了、成长、努力、挑战、克服

**负面关键词（减分）**  
睡过头、什么都没做、失误、失败、摸鱼了、迟到、没能做到

**其他加分项**
- 输入超过 50 字时评分略微提升
- 基础评分从 ★★★（3 星）起步
